# Gesture Recognition System

Welcome to the **Gesture Recognition System** documentation. This project is designed to perform real-time gesture recognition using **MediaPipe**, **FastAPI**, **BentoML**, and **pyautogui**.

The goal of this system is to recognize hand gestures and trigger automated actions such as keyboard presses.

## Key Features:
- **Real-time gesture recognition** with **MediaPipe**.
- **FastAPI** backend for gesture processing.
- **BentoML** service for model deployment.
- **Automation** using **pyautogui** to trigger actions based on gestures.
